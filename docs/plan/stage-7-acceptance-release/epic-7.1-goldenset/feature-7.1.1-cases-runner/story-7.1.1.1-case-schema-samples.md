#### T7.1.1.1.1 用例 JSON schema 与加载器
- **目标：** docs/05 §1 字段的 schema 定义 + 校验加载器。
- **产出：** `acceptance/goldenset/schema.json` + `acceptance/internal/loader.go`。
- **步骤：** 1) 字段与必填约束；2) risk ∈ {p0, p1, p2}；3) 加载期校验（时间格式/ID 格式/tags 枚举）。
- **验收标准：** docs/05 示例用例通过加载；缺字段/坏格式被拒。
- **依赖：** 无。
- **预估：** 1d

#### T7.1.1.1.2 样本集构建（≥100 条）
- **目标：** 覆盖常见问法、改写、无答案、过期知识、权限隔离、provider 故障、配置并发切换（docs/05 §1）。
- **产出：** `acceptance/goldenset/cases/*.json`（≥100 条）+ 覆盖度统计脚本。
- **步骤：** 1) 按 7 类场景分配配额；2) 每例含 expected/forbidden 证据 ID 与 answer facts；3) 去标识化（无姓名/联系方式/token）；4) 覆盖度报告。
- **验收标准：** ≥100 条、七类场景每类 ≥8 条、去标识化抽检通过（O-6 审批人签字）。
- **依赖：** T7.1.1.1.1；O-6。
- **预估：** 2d

#### T7.1.1.1.3 P0 子集冻结
- **目标：** P0 安全集独立标记、版本化冻结流程（变更需重审）。
- **产出：** P0 子集清单 + `goldenset.version` 文件（内容 hash）。
- **步骤：** 1) 标记 risk=p0 用例；2) 冻结清单与 hash；3) 流程说明（修订→审批→重冻结）。
- **验收标准：** P0 子集数量 ≥20 条（建议值，随 O-3 确认）；内容变更可检测。
- **依赖：** T7.1.1.1.2。
