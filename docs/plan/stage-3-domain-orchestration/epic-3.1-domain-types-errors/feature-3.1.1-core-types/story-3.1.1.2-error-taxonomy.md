## 任务

#### T3.1.1.2.1 哨兵错误定义与分类测试
- **目标：** docs/03 §6 七类哨兵错误 + `errors.Is/As` 兼容的包装。
- **产出：** 根包 `errors.go`。
- **步骤：** 1) 定义七类；2) 包装 helper（保留内部原因链，`Unwrap` 供日志）；3) 表驱动测试：任意 provider 错误映射到正确类别。
- **验收标准：** 每类错误 `errors.Is` 判定准确；错误串不含上游响应体/prompt（docs/04 §3）。
- **依赖：** T3.1.1.1.1。
- **预估：** 0.5d

#### T3.1.1.2.2 用户面错误脱敏映射
- **目标：** 定义"错误原文不直接返回用户"的映射层（docs/03 §6）。
- **产出：** `internal/errmap.go`（内部错误→公共错误/Response.Degradation reason 的规则）+ 测试。
- **步骤：** 1) 映射表：timeout→ErrDeadlineExceeded+reason；provider 5xx→Unavailable+reason；contract 违例→ErrProviderContract；2) 内部细节仅进 trace（安全字段）；3) 测试断言公共错误串为固定枚举文案。
- **验收标准：** 遍历内部错误类型，公共面输出仅枚举文案；上游文本零外泄。
- **依赖：** T3.1.1.2.1。
- **预估：** 1d
