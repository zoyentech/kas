# Feature 5.3.1 — 降级编排

> 状态：done ｜ Epic 5.3 ｜ 粗估：2 人日

## 目标

降级链执行器作为 DecisionProvider 的组合实现：顺序固定、每级失败原因可见、终态 abstain/clarify 由规则链兜底语义决定。

## 设计要点

- 顺序来自配置 `fallback.order`，但可用级集合受实现注册限制（未注册级在配置校验期拒绝）。
- 每级尝试在"决策阶段剩余预算"内；超时视为该级失败进入下一级。
- abstain/clarify 是安全终态：链尽或剩余预算不足时输出。
